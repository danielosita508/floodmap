Radar-Based Flood Mapping in Urban Areas

Enhancing satellite radar (Sentinel-1 & Sentinel-2) flood maps with Digital Terrain Models (DTMs) to detect inundation in dense urban and complex environments.

View on GitHub 🚀 Test S1 in Google Colab 🚀 Test S1+S2 in Google Colab

1. Enhancing Flood Maps with DTM (S1)

Uses the FLEXTH algorithm alongside FABDEM 30m Digital Terrain Model to propagate radar flood delineations into excluded or obstructed areas.

View Water Depth Map Run Notebook

2. Merged Sentinel-1 & Sentinel-2 (S1_S2)

Combines radar (Sentinel-1) with optical (Sentinel-2) data to mitigate cloud obstruction and urban backscatter limits, improving extent estimation.

Run Notebook

3. SAR Interferometric Coherence (S1_Coherence)

Detects flash floods and fast-draining urban flood damage by analyzing phase and amplitude coherence drops from Sentinel-1 Single Look Complex (SLC) imagery.

Repository Structure

All files, scripts, and notebooks available in your repository:

  • S1/GFM2FLEXTH.py - Core standalone Python script for S1
  • S1/GFM2FLEXTHnb.ipynb - Interactive Jupyter Notebook for S1
  • S1_S2/FLEXTH_S1S2.py - Python script for combined S1 + S2
  • S1_S2/FLEXTH_S1S2_nb.ipynb - Interactive Notebook for S1 + S2
  • S1_Coherence/Coherence.xml - ESA SNAP radar processing graph

How to Test the Flood Mapping Code

Because this project uses geospatial radar and elevation libraries (GDAL, Rasterio, OpenCV), the easiest ways to test are:

Method 1: One-Click Testing via Google Colab (Recommended)

Click the buttons above to open the notebooks in Google Colab directly from your GitHub repository. Colab provides free cloud compute with pre-configured Python environments.

Method 2: Local Python Environment (Conda / Mamba)

To run locally on your machine, install Miniforge or Anaconda and create the environment:

conda create -n flexth_env python=3.10 gdal rasterio opencv astropy matplotlib jupyter -c conda-forge conda activate flexth_env jupyter notebook
